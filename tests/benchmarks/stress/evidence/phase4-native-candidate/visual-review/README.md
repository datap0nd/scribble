# Phase 4 visual review packet

The contact sheet shows all 18 reference pages. Inspect each linked full-size
PNG in `../reference/` before assigning a verdict. `verdicts.json` records
the SHA-256 of each exact PNG and leaves every verdict `pending` until the
owner reviews it. The files are offline, hand-authored structural references;
they are not outputs from the hosted pilot model.

For each page, mark **approve** or **reject** against this rubric:

1. All text, labels, axes, and table values are legible at full size.
2. No element is clipped, overlapped, or stranded outside its intended area.
3. Hierarchy and contrast make the main claim and evidence easy to follow.
4. The native chart or table remains editable and communicates the correct
   source-backed values.
5. The page has no unexplained visual or factual change from the fixture.

Record a brief reason for every rejection. Approval requires an identified
human reviewer; this packet does not infer approval from native rendering.
